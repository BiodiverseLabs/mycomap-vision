## Instructions

Thank you for doing this check. Each item on this page is a fungus collection carrying a name that was given after DNA sequencing and review. We would like an independent opinion on whether each name is right. Some of the names may be wrong.

### What each item shows

- **The name under review.** Some are provisional code names (for example *Genus* sp. 'CA01') for species-level units that do not yet have a formal name. Judge those the same way: does this collection belong to the unit the code stands for?
- **Photographs** of the collection, and the state or province, month and year.
- **Sequence evidence.** For each of the collection's sequences, the closest matches from two searches: a local database of sequenced collections, and GenBank. Each match gives a name, the identity and the coverage. Names in the local search are the names those sequences carry today. Matches to the collection's own sequences have been removed. Some items have no stored search for one or more sequences; this is noted where it happens.
- A sequence marked **Withdrawn** was later set aside by staff, for example as a poor read or a suspected contaminant. It is shown so that you see everything; weigh it as you think right.

### What we ask for each item

- **Verdict.**
  - *Supported*: what is shown fits the name at species level, and nothing shown contradicts it.
  - *Wrong*: what is shown points to a different species or genus, or the photographs show a different organism from the one the sequences indicate (a mix-up).
  - *Cannot tell*: what is shown is not enough to decide.
- **Better name** (if wrong): the name you would give, at the rank you can support. Click a suggestion or type any name.
- **Shown by**: whether the sequences, the photographs or both led you to your verdict.
- **Recognised**: tick if you believe you know which collection this is, for example because you remember it or handled it.
- **Looked up**: tick if you saw the collection's own page, or any identification of it, anywhere while doing the check, even by accident.
- **Notes**: anything you want to add.

The last two ticks do not count against you; they let us report those items separately.

### Please

- Judge from what is on this page. Do not search for the collection on any website or in any database.
- Do not run the photographs through any identification app, image search or other automated tool.
- If a photograph shows a slip or tag with a number, do not use it to find the collection.
- You may use keys, literature and name databases, and you may open a listed GenBank accession to see what that sequence is.
- Work alone, in any order, and take the time you need. Please do not discuss the items with anyone until you have finished.
- Keep the link to yourself. The photographs belong to their photographers and are shown to you only for this check.

### Saving

Every change saves as you go, and you can change an answer at any time; earlier versions are kept. Use **Unanswered only** to see what is left. Keyboard: 1 / 2 / 3 for the verdict, S / P / B for shown by, R and L for the ticks, / for the better name, the arrow keys or N to move between items. Tell the person who sent you the link when you have finished.
